It is convenient to have a shorthand for `(x : A) → B x` which avoids explicit
naming the variable `x : A`.

```rzk
#def section
  ( A : U)
  ( B : A → U)
  : U
  := (x : A) → B x
```

The type $\Sigma B$ is called `#!rzk total-type A B` in rzk; and $\pi_*$ is
called `#!rzk projection-total-type`. If the diagram commutes, the function $s$
is called a section, since $\pi_B \circ s = \text{id}_A$. However, since we know
more information about the structure of the total type $\Sigma B$, specifically
that it's a sigma type over $B$; we can form the type $\Pi_{a : A} B(a)$ of
strict sections which we called `#!rzk section A B` above. These are _strict_,
since for all $s : \Pi_{a : A} B(a)$ we have that
$\text{refl} : \pi_B \circ s = \text{id}_A$.

## Composing type families

```rzk
#def type-family-comp
  ( A : U)
  ( B : A → U)
  ( C : total-type A B → U)
  : A → U
  := \ a → Σ (b : B a) , C (a , b)

#def uncurried-type-family-comp
  ( A : U)
  ( B : A → U)
  ( C : (a : A) → (b : B a) → U)
  : A → U
  := \ a → Σ (b : B a) , C a b
```
