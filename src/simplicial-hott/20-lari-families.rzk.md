## Definition

In this section, we formalize the notion of LARI families covered by
[Buchholtz and Weinberger (2023), Higher Structures 7](https://doi.org/10.21136/HS.2023.04).
There are some small differences between this formalization and Buchholtz's and
Weinberger's definition that help make it more concise.

Buchholtz and Weinberger's definition is the following: given $P: B \to
\mathcal{U}$, it is a LARI family if and only if the dashed map (which is the
Leibniz-cotensor map) forms a LARI adjunction.

This observation allows us to define LARI-families with a lighter definition
that directly relies on the `#!rzk has-dependent-initial` notion that is
simpler, but equivalent to the notion of LARI adjunction.

```rzk
#section LARI-families

#variable I : CUBE
#variable X : I → TOPE
#variable Y : X → TOPE

#def LARI-family-domain
  ( B : U)
  ( P : B → U)
  : U
  := Σ (g : X → B) , (y : Y) → P (g y)

#def LARI-family-codomain
  ( B : U)
  ( P : B → U)
  ( ( g , f₀) : LARI-family-domain B P)
  : U
  := (x : X) → P (g x) [Y x ↦ f₀ x]

#def is-LARI-family
  ( B : U)
  ( P : B → U)
  : U
  :=
  ( g : X → B)
  → ( f₀ : (y : Y) → P (g y))
  → has-dependent-initial
    ( LARI-family-domain B P)
    ( LARI-family-codomain B P)
    ( g , f₀)
```

Due to this definition, we can prove the following facts via unfolding it:

```rzk
#def section-is-LARI-family uses (I X Y)
  ( B : U)
  ( P : B → U)
  ( is-LARI-family-P : is-LARI-family B P)

  :=
  \ (g , f₀) → first (is-LARI-family-P g f₀)

#def is-dependent-initial-section-is-LARI-family uses (I X Y)
  ( B : U)
  ( P : B → U)
  ( is-LARI-family-P : is-LARI-family B P)

    ( LARI-family-domain B P)
    ( LARI-family-codomain B P)
    ( section-is-LARI-family B P is-LARI-family-P)

  \ (g , f₀) → second (is-LARI-family-P g f₀)

#def is-LARI-family-is-dependent-initial-section uses (I X Y)
  ( B : U)
  ( P : B → U)
  ( s : ((g , f₀) : LARI-family-domain B P) → LARI-family-codomain B P (g , f₀))
  ( is-dependent-initial-section-s
 : is-dependent-initial-section
      ( LARI-family-domain B P)
      ( LARI-family-codomain B P)
      ( s))
  : is-LARI-family B P
  := \ g f₀ → (s (g , f₀) , is-dependent-initial-section-s (g , f₀))
```

## Closure Properties

Since we defined LARI families as dependent initial sections, we can translate
their closure from to this concrete definition. It takes quite some mechanical
effort to translate the data, but no special idea is required.

One such mechanical ingredient is the next lemma, which is a "theorem of choice"
for `#!rzk dhom` of `#!rzk LARI-family-domain`:

Lastly, to show that the composition of two LARI families is again a LARI
family, we need to work quite a bit, despite the mathematical insight being
quite straight-forward.

We begin the proof with a lemma that shows that we can swap sigma and `#!rzk
LARI-family-codomain` in a specific way.

```rzk
#def equiv-LARI-family-codomain-sigma-swap
  ( B : U)
  ( P : B → U)
  ( is-LARI-family-P : is-LARI-family B P)
  ( R : (total-type B P) → U)
  ( is-LARI-family-R : is-LARI-family (total-type B P) R)
  ( ( g , f₀) : LARI-family-domain B (\ b → Σ (p : P b) , R (b , p)))
  : Equiv
    ( Σ ( F : LARI-family-codomain B P (g , \ y → first (f₀ y)))
      , LARI-family-codomain (total-type B P) R
        ( \ x → (g x , F x) , \ y → second (f₀ y)))
    ( LARI-family-codomain B (\ b → Σ (p : P b) , R (b , p)) (g , f₀))
  :=
  equiv-has-inverse
  ( Σ ( F : LARI-family-codomain B P (g , \ y → first (f₀ y)))
    , LARI-family-codomain (total-type B P) R
      ( \ x → (g x , F x) , \ y → second (f₀ y)))
  ( LARI-family-codomain B (\ b → Σ (p : P b) , R (b , p)) (g , f₀))
  ( \ F x → (first F x , second F x))
  ( \ F → (\ x → first (F x) , \ x → second (F x)))
  ( \ _ → refl)
  ( \ _ → refl)
```
